# 🚀 Sky Blasty

Top-Down Arcade Shooter für Mobile. Gebaut mit Vite + Svelte + HTML5 Canvas.

## Spielen

Nach dem Deployment auf GitHub Pages:
**https://verapas.github.io/sky-blasty/**

## Steuern

- 👆 **Finger bewegen** = Flieger steuern
- 🔥 **Auto-Fire** ist immer aktiv
- ⭐ **Power-ups** einsammeln: Waffen-Upgrades, Schilde, Extra-Leben

## Lokal entwickeln

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Tech

- Vite + Svelte
- HTML5 Canvas Rendering
- GitHub Actions Auto-Deploy auf GitHub Pages
